USDA FSIS Inspection Directory.

Pull every federally-inspected meat plant in the country into our discovered_partners table. We filter for slaughter + processing operations that handle the species we care about (cattle, hogs, sheep, goats, bison, deer/elk). After import, send invites from the admin overview.

1 Download the FSIS directory

Open fsis.usda.gov/inspection/establishments in a new tab. Click the Excel/XLSX download for "Meat, Poultry, and Egg Product Inspection Directory." Updated monthly. ~6,000 rows.

2 Save as CSV

Open the XLSX in Excel, Numbers, or Google Sheets. File → Save As → CSV (Comma-Separated Values). The first row should be column headers like "Establishment Number", "Establishment Name", "City", "State", "Activities", "Inspection Type", "Species".

3 Upload CSV here

Either drag-drop the file or paste the raw CSV text. We'll filter for relevant plants (federal + meat + cattle/hogs/sheep/goats/bison/deer) and insert into the staging table.
