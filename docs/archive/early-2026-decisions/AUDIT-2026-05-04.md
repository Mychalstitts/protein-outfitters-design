## 🟡 SYSTEMIC GAPS

These aren't bugs — they're missing features that the demos imply exist:

1. **No Stripe integration** — no real payment processing. Reserve flow's "Pay deposit" button doesn't actually charge. No webhooks, no refunds, no payouts.
2. **No insurance pool** — `/admin` shows "Pool ($28k)" but no pool table in DB, no logic for the 2% / $50 condemnation insurance Trello decision.
3. **No `transactions` / `payouts` / `disputes` tables** in DB.
4. **No customer service / ticketing** — no admin inbox, no auto-routing of issues.
5. **No Stripe Connect** for farmer/processor payouts.
6. **No real geocoding** — farms don't have lat/lng so /map can't actually plot them precisely (relies on Maps Geocoding API).
7. **Dashboards (farmer, processor, admin)** are presentation-only. Backend tables exist (listings, farms, reservations, processors, reviews) but pages don't query them.
